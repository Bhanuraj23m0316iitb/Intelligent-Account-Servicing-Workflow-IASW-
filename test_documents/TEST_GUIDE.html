📋 Step-by-Step: How to Run Each Test

For Every Test Case — Same 5 Steps

  1. Open the .html file from test_documents/ in Chrome
  2. Press Ctrl+P → Change printer to "Save as PDF" → Click Save
  3. Go to http://localhost:3000/intake and fill in the form values from the table above
  4. Upload the saved PDF in Step 3 of the intake wizard
  5. Click Submit for AI Verification → Wait ~5-10s → Review results → Approve or Reject
💡 Screenshot trick (no PDF needed): Open HTML in Chrome → F12 → Toggle device toolbar → Set width 860 → Right-click page → Capture screenshot → Upload the PNG directly. The app accepts PNG images too!
🔒 Checker Approval — Same for All Tests
After AI pipeline completes → Go to Checker Review page → Enter Checker ID: CHECKER001 → Click Approve → Confirm → Done!
